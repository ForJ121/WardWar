# WardWar

WardWar 是一个使用 **C++ + raylib** 开发的轻量级 2D 本地双人对战游戏。

项目目前仍处于开发阶段，现阶段主要目标是完成一个完整、可扩展的 2D 对战系统，并在此基础上逐步加入更多角色、技能、地图和游戏模式。

---

## 项目简介

WardWar 当前支持本地双人 PVP。

两名玩家可以在不同地图中移动、跳跃、攻击、防御并释放技能，通过消耗对方生命值来取得胜利。

目前已经实现了从：

> 主菜单 → 模式选择 → 地图选择 → 战斗 → 胜负判定 → 重新开始

这一套基本游戏流程。

PVE 模式目前已经预留入口，但尚未正式实现。

## 操作方式

### Player 1

| 操作        | 按键  |
| ----------- | ----- |
| 向左移动    | A     |
| 向右移动    | D     |
| 向上 / 跳跃 | W     |
| 向下 / 蹲下 | S     |
| 普通攻击    | J     |
| 防御        | Space |
| 技能 1      | K     |
| 技能 2      | L     |

### Player 2

| 操作        | 按键     |
| ----------- | -------- |
| 向左移动    | ←        |
| 向右移动    | →        |
| 向上 / 跳跃 | ↑        |
| 向下 / 蹲下 | ↓        |
| 普通攻击    | 小键盘 1 |
| 防御        | 小键盘 0 |
| 技能 1      | 小键盘 2 |
| 技能 2      | 小键盘 3 |

当前两个玩家的按键配置直接在初始化阶段进行设置。
